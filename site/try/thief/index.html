Practice · an experiment

A site that robs whoever connects.

This page plays a thief. It does what a wallet-draining site does: it waits for a wallet to connect, takes it that the wallet holds 310 SOL and 40,000 USDC, and asks it to sign all of that away to an address of its own. It is connected to no blockchain, the wallet below is a practice wallet that holds nothing, and nothing is ever sent anywhere.

With Warden in this browser, the address this page is handed when it connects is not the practice wallet's. It is a decoy's: an address nobody has a key to. What the thief asks the decoy for is how Warden knows what it is.

See a site that is not a thief: the decoy must not get in its way.

A site that only wants to be paid.

This page plays an ordinary site. It connects to a wallet and asks it for half a SOL. It is connected to no blockchain, the wallet below is a practice wallet that holds nothing, and nothing is ever sent anywhere.

With Warden in this browser, this page too is handed a decoy first. What it asks the decoy for is ordinary, so Warden lets the practice wallet take the decoy's place, and the site asks again.
